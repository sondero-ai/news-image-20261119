## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`), creating the output directory when it is missing. It uses only the Node standard library, makes no network calls, and writes the same bytes on every run.
